# Product

## Register

product

## Users

Front-end developers who want to create and refine local React applications through
conversation while keeping direct access to the preview and generated source files.

## Product Purpose

Gamma Compose turns templates, browser-local project files, and an Agent into a fast
application-building workbench. Success means a developer can describe a change, see
the real application respond, inspect the source, and continue refining without losing
the sense that the work remains under their control.

## Brand Personality

Restrained, precise, and geek. The interface should feel like a focused developer
instrument: quiet enough to disappear during work, explicit enough to remain trusted.

## Anti-references

- Marketing copy inside the workbench.
- Ornamental AI-dashboard styling, glass effects, gradients, and decorative motion.
- Provider credentials, implementation details, or speculative usage metrics exposed as user status.
- Toolbars filled with unavailable controls or labels that compete with the task.

## Design Principles

1. Keep the generated application and the conversation in one continuous working context.
2. Show only truthful, actionable state; hide infrastructure details from product copy.
3. Preserve familiar developer-tool affordances and dense, predictable interaction patterns.
4. Let the interface recede: hierarchy comes from alignment, spacing, and state, not decoration.
5. Introduce capabilities only when the underlying workflow is real and complete.

## Accessibility & Inclusion

Target WCAG 2.2 AA contrast and keyboard operation. Preserve visible focus, support IME
composition, honor reduced-motion preferences, and keep controls usable in narrow,
user-resized panels without relying on color alone.
